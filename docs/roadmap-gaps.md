# 平台机制缺口与后续规划（v1.28 审计）

本文件记录 v1.28 发版前对代码的全量审计结论：业务功能基本齐备，后续重点在平台级机制。
判断以代码为准（路由约 480 条），「缺失」表示全仓库无对应实现。工作量：小（≤2 天）/ 中（≤1 周）/ 大（>1 周）。

## P0：安全与可靠性必需

| 项 | 现状 | 建议 | 工作量 |
| --- | --- | --- | --- |
| 主机 Agent 多副本 | 部署清单 2 副本，`hosts/hub.go` 连接只在本副本内存，跨副本命令会报 agent offline | 复用集群隧道的 PG 登记 + HMAC 转发；或改为 DB 任务表由持有连接的副本认领 | 中 |
| API Token / 服务账号 | 只有会话 JWT | 个人 / 服务账号令牌：只存哈希、权限子集、到期、最后使用时间、吊销，审计记录调用方 | 中 |
| MFA | 无 | TOTP + 恢复码，可按角色强制；堡垒机连接与生产变更二次验证 | 中 |
| 审计防篡改 | 只记非 GET；到期直接 DELETE；无导出 | `prev_hash/hash` 哈希链与校验接口；到期先归档到对象存储；CSV/JSON 导出；敏感读（查看录像、Secret）显式记审计 | 中 |
| 平台自身备份 | 仅集群级 Velero | 定时 pg_dump 到 S3、升级前自动快照、恢复手册与演练 | 中 |
| 密钥轮换 | 单一 AES 主密钥、单一 HS256 | 密钥环（kid）、后台重加密任务、JWT kid 轮换，预留 Vault/KMS | 中 |
| 就绪探针与指标暴露 | `/healthz` 固定 ok；`/metrics` 无认证 | 新增 `/readyz`（DB、迁移）；`/metrics` 独立端口或 Bearer | 小 |

## P1：主流平台的核心机制

| 项 | 现状 | 建议 | 工作量 |
| --- | --- | --- | --- |
| 多租户（企业空间） | 项目 = 命名空间，已有 Quota / LimitRange | 企业空间 → 项目（跨集群）→ 成员角色，配额按空间汇总 | 大 |
| RBAC 数据范围 | 仅按环境限定 | 角色绑定加集群 / 命名空间 / 应用 / 资产组范围，列表统一过滤 | 大 |
| OpenAPI | 手写 Markdown | 自动生成 OpenAPI 并挂载文档页，契约测试 | 中 |
| 分布式限流 | 进程内令牌桶，仅登录类接口 | Redis 限流，按用户 / Token / 路由分级 | 小 |
| 安全响应头、WS 令牌 | nginx 无 CSP/HSTS；WS 用查询参数传令牌 | 补安全头；WS 改一次性票据 | 小 |
| 镜像安全扫描 | 无 | 流水线 Trivy 阶段与高危门禁，或读取 Harbor 扫描结果 | 中 |
| 灰度 / 金丝雀 | 仅滚动与回滚 | Argo Rollouts 或网关权重分步放量，按指标自动回滚 | 大 |
| 证书到期提醒 | 能列出并计算状态 | 新增证书事件，按 30/7/1 天推送订阅；对接 cert-manager | 小 |
| 后台任务自动重试 | 只能手动重试 | attempts、next_run_at、指数退避、死信 | 中 |
| 幂等键 | 无；Git webhook 不去重 | `Idempotency-Key` 中间件；webhook 按 delivery 去重 | 小 |
| 迁移回滚 | 只有 up 脚本 | 升级前自动快照 + 回滚手册；`/version` 返回 schema 版本 | 中 |
| 平台自身可观测 | 只有 HTTP 指标 | 队列积压、Agent 在线数等业务指标；OTel；随附面板与告警规则 | 中 |
| 日志采集 | 能查 ES/Loki | 组件目录一键安装 Fluent Bit / Vector 并自动绑定数据源 | 中 |
| 告警静默与自动转故障 | 可手动从告警建故障 | 匹配规则自动建单；Alertmanager silence 管理 | 中 |

## P2：增强

软删除与回收站、统一乐观锁（`If-Match` / 409）、自动化工作流定时触发、个人通知偏好与站内信、Helm Release 升级 / 回滚 / 卸载与 OCI、GitOps 应用创建与漂移告警、VPA / KEDA、跨集群总览与分发、配置中心、成本分析（OpenCost）、业务数据导出、SSO ID Token 签名校验（JWKS + nonce）、会话空闲超时与并发上限、国际化、关于页与第三方许可声明。
