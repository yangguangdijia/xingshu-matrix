## 执行顺序

1. 可观测：集群监控分层标签 → 资源用量排行 → 模板化告警规则 → 告警静默/订阅
2. CI/CD：流水线列表 → 运行详情阶段图 → 图形化编排 + YAML → 从源码创建
3. 系统设置：身份提供者 → 外观 → 邮件服务
4. 应用交付：应用拓扑 → 组件详情标签组
